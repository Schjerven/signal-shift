# SIGNAL SHIFT — Creator Edition

**Created by Kjetil Schjerven · Built with AI assistance**

SIGNAL SHIFT is a retro-inspired browser arcade game for desktop and mobile. The idea, design choices and hands-on testing are led by Kjetil Schjerven, with AI used as a development partner.

**Technology:** HTML for structure, CSS for design, JavaScript for gameplay, and Python for reference logic and testing. The actual browser game runs JavaScript, not Python.

## How to play

Collect energy, charge SHIFT and avoid colliding with your own trail. Cross any edge to appear on the opposite side. Control with arrow keys/WASD or mouse on PC and touch/swipe on mobile. Pause/resume, select themes and toggle music or effects in the game.
